**Timing.** Replies took 7.9 to 18.7 s, with the first token after 1.9 to 5.4 s. The context held 1,323 to 1,510 tokens.

**Note on "move call mom to friday".** The app's new no-change check refused this update, and it was right to. At 09:26:54 a hand tap on the home screen's Done checkbox had already moved the daily "Call mom" from Thursday the 19th to Friday the 20th. The same happened to "Wake up" at 09:26:48 and "Daily stand up" at 09:26:49. The phone's input log shows taps in Remind Me's window at x≈85 to 114, the checkbox column. Done before the due time skips the coming occurrence, as build 1 specifies. So the model's update asked for what the task already had.

**Takeaway for this map.** Most failures are date and time arithmetic and invented repeat rules. Both point at the code working out dates from words, and at a tighter tool contract.
