# Task and repeat rule model

Type: grilling
Status: claimed
Blocked by: none
Map: [Remind Me v1](../map.md)

## Question

What exactly is a task?

- Which properties does a task have beyond title, due time, lead time, repeat rule and delivery style?
- Which repeat rules exist in v1 (once, daily, chosen weekdays, every N days or weeks, monthly, yearly), and can a repeat rule end?
- Can a task have more than one lead time ("a day before and an hour before"), and is the due time itself always announced?
- What states does a task move through (upcoming, fired, done, missed, deleted), and what does "done" mean for a repeating task: this occurrence or the whole task?
- Is a due time always a date and a time, or can a task be date-only?
- What happens to a one-time task after it fires and is dismissed: kept as history or removed?
